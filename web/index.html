FEATURES OF THE LAB

  • Capture — configurable frequency, sample rate, gains & trigger modes with auto-carved recordings.
  • Live FFT + waterfall — zoom, pan and peak-hold, processed off the UI thread.
  • Concurrent TX — white/Gaussian noise, CW, sine or your own IQ waveform.
  • Structured sessions — cs16 recordings, metadata & an FFT cache, all local.
  • Playback — replay any recording through a selected transmitter.
  • Beacon — key any message as looping International Morse (CW).
  • Jam — a dedicated transmitter with a live affected-band overlay.
  • Debug — A/B compare recordings with overlaid FFTs and measurements.
Portable to ARM / Raspberry Pi. Touch-friendly 320×480 UI.
